# 账号命名

## 推荐

**故纸余温**（首选）

- 含义：故纸 = 旧档案、旧书信、旧史；余温 = 人留下的温度。
- 契合“历史中的人性与情感”，四个字好记，抖音/B站都不违和。
- Slogan：`在旧纸堆里，打捞人的温度。`
- 简介：`每周三更新，一个被遗忘的人，一段不该被忘记的往事。`

## 备选

| 名称 | 气质 | 适合 | 风险 |
|---|---|---|---|
| 故纸余温 | 文学、温暖、品牌感 | 抖音/B站主号 | 需查重名 |
| 旧事人间 | 通俗、直接、大众 | 抖音优先 | 可能偏泛 |
| 史间烟火 | 有画面、有人间气 | 双平台 | 略文艺 |
| 纸上故人 | 书信/档案感 | B站/小红书 | 稍窄 |
| 人间旧档 | 系列感强 | 作为系列名 | 作为账号略像栏目 |

## 定名前的检查

1. 抖音、B站分别搜索同名，确认没有同赛道大号。
2. 检查是否有同名书籍/电影/综艺/商标（尤其第 41 类教育娱乐、第 35 类广告）。
3. 若被占用，用后缀：`故纸余温·人间`、`故纸余温讲历史`、`故纸余温的旧档`。
4. 两个平台用同一名称、同一头像、同一简介结构，方便跨平台识别。
5. 名称确认后改 `config/account.json` 的 `name` 和 `handle`。

## 不建议

- 直接用《历史的温度》《山河故人》《国家宝藏》《如果国宝会说话》等已有知名作品名。
- 名称里堆“历史”“揭秘”“未解之谜”等泛词，容易同质化。
- 名称过长、带生僻字、带数字/年份。
