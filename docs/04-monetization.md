# 变现与路线图

## 现实预期

- 2000 元/月 = 2.4 万/年。回本不能靠播放量收益，要靠“星图 + 带货 + 私域/课程”的组合。
- 0–3 个月：投入期，基本无收入。
- 3–6 个月：可能出现小额星图、书籍/文创佣金、B站/视频号少量分成。
- 6–12 个月：若到 1–3 万粉且有 1–2 条小爆款，有机会覆盖 2000/月并开始回本；不保证。
- 12 个月以后：品牌年框、课程/私域、IP 授权才是放大阶段。

## 收入路径

| 路径 | 门槛（行业信息，需以官方为准） | 适合 |
|---|---|---|
| 星图商单 | 入驻无粉丝硬门槛，具体任务有门槛；约 500–1000 粉可接小额 | 主号 |
| 商品橱窗/带货 | 约 500 有效粉 | 书籍、文创 |
| 中视频伙伴计划 | 横屏 ≥1 分钟、累计 17000 播放（规则可能调整） | 历史/纪实 |
| 广告分成 | 约 1 万粉 | 主号 |
| B站创作激励/充电/商单 | 开通创作激励后有播放分成 | 长尾/深度 |
| 知识付费/私域 | 需要信任与案例 | 6 个月后 |
| 小说推文/短剧分销 | 0 粉可做，CPS 约 50–70% | 副号/快钱 |

## 小说推文：更快，但不是同一条路

| 维度 | 主号（历史情感） | 小说推文号 |
|---|---|---|
| 起量 | 慢，3–6 个月 | 快，几天到几周 |
| 变现 | 慢，但可积累品牌/IP | 快，CPS 分成 |
| 天花板 | 高 | 低，本质是广告号 |
| 粉丝价值 | 高 | 低 |
| 内容成本 | 高（脚本/考据/生成） | 低（图文/混剪/口播） |
| 风险 | 史料/合规/同质化 | 授权/版权/限流/封号 |
| 与主号关系 | 品牌资产 | 不要混发，必须另开号 |

**建议**：现在不要开。先用 8–12 周把主号跑通；如果现金流紧张，再另开一个推文号，每周投入 3–5 小时做测试，不动主号。推文号的收入不要用来补贴主号的高成本制作，否则两边都做不好。

## 12 个月路线

- 0–2 月：定位、10 个对标、50 条拆解、4 条试播；验证“AI 画面 + 你的旁白”。
- 3–4 月：固定系列与周更；抖音/B站双平台；建立数据台账。
- 5–6 月：冲第一条小爆款；测试钩子/时长/发布时间；开始书籍/文创带货。
- 7–9 月：稳定 1–3 万粉；星图小额单；B站合集/长尾；私域入口。
- 10–12 月：评估是否转微电影/特别篇；是否开推文副号；是否做课程/付费内容。

## 不要做的事

- 不要买粉、刷量、群控；短期数据好看，长期毁账号。
- 不要为了接广告改赛道；历史情感号的品牌价值在“可信”。
- 不要把所有预算压在一条“可能爆”的视频上；周更的复利更重要。
