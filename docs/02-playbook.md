# 内容 Playbook

## 单集结构（2–3 分钟）

| 时间 | 任务 |
|---|---|
| 0–3s | 反常识/悬念/一句冲突，直接给钩子 |
| 3–15s | 交代时间、地点、人物、问题 |
| 15s–1min | 第一幕：建立处境与冲突 |
| 1–1.8min | 第二幕：转折与代价 |
| 1.8–2.5min | 第三幕：选择与结果 |
| 2.5–3min | 收束：情感升华 + 一个开放问题 |

每 20–30 秒必须有一个转折、信息增量或视觉爆点；不要连续 30 秒同一画面。

## 钩子库（每期换一种）

1. 反常识：`她被画进敦煌壁画，但画师没有留下她的名字。`
2. 悬念：`这封信寄出后，收信人等了她一千三百年。`
3. 数字：`一座墓里只有三件东西，其中一件属于一个不该出现的人。`
4. 对比：`同一时代，有人在写诗，有人在被写成数字。`
5. 第一人称：`如果你是我，你会不会也做同样的选择？`
6. 物件：`这枚铜镜背面，刻着一个被史书删掉的名字。`
7. 时间：`公元 848 年，一个普通女人做了一个不普通的决定。`
8. 冲突：`他救了全城的人，史书却只记了他一句“不知所终”。`
9. 疑问：`为什么她的墓志铭，只有 27 个字？`
10. 情绪：`她等了十年，等来的不是丈夫，是一纸休书。`

## 事实与来源规则

- 每条关键事实必须进 `brief.json` 的 `key_facts`，并带来源。
- 至少 3 条有来源的事实；没有来源的细节宁可不写。
- 区分“史实/推断/文学化表达”；简介或置顶评论写清来源。
- 不碰野史、秘闻、无依据的“考古发现”；不做伪历史。
- 引用论文/博物馆/权威出版物时，写书名/文章名 + 页码或链接。

## 制作流程

1. **选题**：从选题库/热点宝/评论区来，一句话说清“这期讲谁、发生了什么、为什么现在讲”。
2. **考据**：3–5 个来源，整理事实清单；写 brief。
3. **脚本**：旁白 600–1000 字；先写钩子和结尾，再填中间。
4. **分镜**：15–25 个镜头，5–8 秒/镜；先 720p。
5. **生成**：Seedance 2.x 主力；关键镜头用可灵 4.0；对白/特写用海螺 H3。
6. **剪辑**：剪映；旁白先定节奏，再贴画面；字幕关键词加粗；BGM 低于人声。
7. **审片**：事实、AIGC 标识、版权、敏感词、封面/标题、双平台差异。

## 8 周节奏

- 第 0 周：对标 10 个账号、拆 50 条；注册账号；开通工具；建选题库。
- 第 1 周：试播 A（2–3 分钟），抖音+视频号/B站手动发。
- 第 2 周：复盘 A；试播 B（换钩子/结构）；B站发竖屏或合集。
- 第 3–4 周：定系列 EP01/EP02；固定周更；评论区运营。
- 第 5–8 周：迭代钩子/封面/标题；每周加 1 条图文/切片；第 8 周决策。
- 决策线：完播中位数 <25% 改钩子/节奏；互动 <2% 改结尾；某条 >3 倍中位数，复制该题材。

## 实验台账

每条视频只改一个变量：
- 钩子类型（反常识/悬念/第一人称）
- 时长（2min vs 3min）
- 开头 3 秒是否有字幕
- 结尾是否有开放问题
- 发布时间（周三 vs 周五）

实验记录写进 `copilot experiment add`，周报里看结果，结论写进 `playbook`。

## 发布前检查

- 标题、封面、话题是否与内容一致，不标题党。
- AIGC 标识是否添加；音乐/字体/素材是否有版权。
- 史料来源是否写清；有没有绝对化/煽动性表述。
- 抖音版无 B站水印；B站版简介完整。
- 数据记录表是否准备好（1h/24h/7d）。
